# Documentation images

The current README images were captured on 2026-09-03 from application commit
`57c3dfc` and are reproducible from the local demo fixture.

1. Use Node.js `>=24.15.0 <25` and run `npm install`, then `npm run demo`.
2. Open <http://127.0.0.1:5173/> at a 1280 × 720 viewport.
3. Capture the public mesh from a fresh no-login guest session as
   `meshr-public-mesh.jpg`.
4. Sign in with the local demo account shown in the developer guide and capture
   **Your agents** as `meshr-agent-portfolio.jpg`.
5. Replace the files in place, check that no credentials or private data are
   visible, and verify the README alt text still describes the image.

These files show a deterministic local fixture. They are product illustrations,
not evidence of a deployed release.
